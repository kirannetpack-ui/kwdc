## 🔴 Critical Issues (Fix This Week)

### 1️⃣ User Type Column Redundancy ⏱️ 1 hour
```
Status: Multiple overlapping columns
Before: role, is_admin, is_driver, is_equipment_owner, user_type
After:  role (primary) + roles (JSON array)
Impact: Data integrity, cleaner queries, multi-role support
```

### 2️⃣ Coordinates Stored as VARCHAR ⏱️ 1 hour
```
Status: kataho_locations.latitude/longitude are strings
Before: $table->string('latitude')
After:  $table->decimal('latitude', 10, 8)
Impact: Enable geospatial queries, better performance
```

### 3️⃣ Missing Foreign Key Cascades ⏱️ 30 min
```
Status: invoices.warehouse_request_id lacks cascade
Before: $table->foreignId('warehouse_request_id')...
After:  ...->onDelete('cascade')->onUpdate('cascade')
Impact: Referential integrity, prevent orphaned records
```

### 4️⃣ Confusing Date Columns ⏱️ 30 min
```
Status: driver_rates has 4 similar columns
Problem: effective_from, effective_until, effective_to, valid_until
Solution: Standardize to effective_from and effective_until
Impact: Clearer business logic
```

## 🟡 High Priority Issues (This Sprint)

### 5️⃣ Missing Performance Indexes
- **Current:** No compound indexes
- **Impact:** Slow reports, dashboards, queries
- **Solution:** Add 10+ compound indexes
- **Examples:** `(client_id, status)`, `(driver_id, status)`
- **Benefit:** 10-100x faster queries
- **Effort:** 1 hour

### 6️⃣ No Soft Deletes
- **Current:** 0 tables with soft deletes
- **Impact:** Can't recover deleted data, breaks referential integrity
- **Solution:** Add soft deletes to 8 core tables
- **Benefit:** Full data recovery, audit trail
- **Effort:** 1.5 hours

### 7️⃣ No Audit Trail
- **Current:** No activity logging
- **Impact:** Can't track changes, audit compliance issues
- **Solution:** Create `activity_logs` table with model trait
- **Benefit:** Complete change history, compliance ready
- **Effort:** 1 hour
